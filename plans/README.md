## Findings considered and rejected

- **Committed secrets in `.env.development.local`** — file is untracked by git
  (`git ls-files` shows only `.env.*.example` files). The agent read a local
  untracked file. No rotation needed.
- **Cancel-route null crash on missing `acceptedAt`** — guarded by
  `if (earliestSend)` at `cancel/route.ts:79`. Not a bug.
- **Weak verification-code entropy (6 bytes)** — linking requires the victim
  to put the code in their own Cosmo status message; brute-forcing is not useful
  without controlling that profile. Rate limiting already present. Not worth
  changing.
- **CSRF on API routes** — Better Auth cookies default to `SameSite=Lax`, which
  blocks cross-site POSTs. Not actionable without evidence of a bypass.
- **npm audit moderates (esbuild/postcss)** — dev-time only, transitive via
  drizzle-kit / Next.js internals; not actionable without a drizzle-kit major
  bump causing wide blast radius.
- **Stack trace exposure in proofshot error response** — rembg is a first-party
  service; low practical risk. Not planned.
- **Spin odds untested** — noted as a direction finding, not a bug. Not planned
  here; add to a future sprint if spin is promoted from experimental.
- **God file (check-transfers 846 lines)** — high refactor risk on an actively
  working critical path. Deferred until test coverage (plans 003+004) is in
  place. Not planned in this batch.
