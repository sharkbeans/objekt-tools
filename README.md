# objekt.my

Fan-made tools for [MODHAUS](https://www.mod-haus.com/)' **[Cosmo: the Gate](https://play.google.com/store/apps/details?id=com.modhaus.cosmo)** collectors.

**objekt.my is not affiliated with, endorsed by, or supported by MODHAUS or its artists.**

## Tools

**[Trades](https://objekt.my/trades)** — Browse, post, and match Cosmo objekt trades.

**[Lists](https://objekt.my/list)** — Build and share clean have/want trade lists.

**[Collection](https://objekt.my/collection)** — Track collection progress by member and season.

**[Objekt Maker](https://objekt.my/objekt-maker)** — Create custom objekt cards.

**[Proofshot](https://objekt.my/proofshot)** — Generate proofshot images.

**[Spin](https://objekt.my/spin)** — Run random draw simulations.
